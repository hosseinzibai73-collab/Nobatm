# نوبتم — راهنمای انتشار روی گیت‌هاب

این پوشه یک پروژه‌ی کامل و آماده است. کافیه محتوایش رو در یک ریپازیتوری گیت‌هاب قرار بدی تا به‌صورت خودکار روی اینترنت منتشر بشه و از گوشیت بازش کنی.

## مراحل

1. یک ریپازیتوری جدید در گیت‌هاب بساز، مثلا با اسم `novbatam` (Public).
2. تمام فایل‌های این پوشه (`index.html`, `package.json`, `vite.config.js`, پوشه‌ی `src`, پوشه‌ی `.github`) رو داخل همون ریپازیتوری آپلود کن.
   - ساده‌ترین راه: در صفحه‌ی ریپازیتوری روی «Add file → Upload files» بزن و همه‌ی فایل‌ها/پوشه‌ها رو بکش و رها کن، بعد Commit کن.
3. برو به تنظیمات ریپازیتوری: **Settings → Pages**
   - در قسمت «Build and deployment» گزینه‌ی **Source** رو روی **GitHub Actions** بذار.
4. یک بار دیگه هر تغییری commit کن (یا از قسمت Actions روی workflow کلیک کن و Run کن) — ورک‌فلوی داخل `.github/workflows/deploy.yml` به‌صورت خودکار پروژه رو build و منتشر می‌کنه.
5. بعد از چند دقیقه، لینک سایت در همون صفحه‌ی Settings → Pages نمایش داده می‌شه (چیزی شبیه `https://USERNAME.github.io/novbatam/`).
6. اون لینک رو توی مرورگر گوشیت باز کن. برای این‌که شبیه یک اپ واقعی روی صفحه‌ی اصلی گوشی بشینه:
   - **اندروید (Chrome):** منوی سه‌نقطه → «Add to Home screen»
   - **آیفون (Safari):** دکمه‌ی Share → «Add to Home Screen»

## نکته‌ی مهم درباره‌ی ذخیره‌سازی اطلاعات

نسخه‌ای که داخل چت کلود دیدی، اطلاعات رو در حافظه‌ی مخصوص کلود ذخیره می‌کرد. این نسخه (داخل همین پوشه) به‌جای اون از **حافظه‌ی مرورگر گوشی (localStorage)** استفاده می‌کنه، یعنی:

- اطلاعات فقط روی همون گوشی/مرورگری که باهاش کار می‌کنی ذخیره می‌مونه.
- اگه Cache مرورگر رو پاک کنی یا از مرورگر دیگه‌ای وارد بشی، اطلاعات از اول شروع می‌شه.
- برای هماهنگی بین چند دستگاه یا بک‌آپ ابری، بعدا نیاز به یک دیتابیس واقعی (مثل Supabase یا Firebase) خواهد بود که در صورت تمایل می‌تونم توی مرحله‌ی بعد اضافه‌اش کنم.
- برای پشتیبان‌گیری دستی، از همون بخش «پشتیبان‌گیری» توی منوی داخل اپ استفاده کن.

## ساخت فایل APK (بدون نیاز به Android Studio)

این پوشه الان یک PWA کامل شده (manifest + آیکن‌ها + service worker)، پس می‌تونی با سرویس رایگان **PWABuilder** یک فایل APK واقعی ازش بگیری، بدون نصب هیچ نرم‌افزاری روی کامپیوتر.

**پیش‌نیاز:** باید اول همین پروژه رو طبق بخش «مراحل» بالا روی گیت‌هاب Pages منتشر کرده باشی و یک لینک زنده (مثل `https://USERNAME.github.io/novbatam/`) داشته باشی.

1. برو به سایت **pwabuilder.com**
2. لینک زنده‌ی اپت رو توی کادر بذار و بزن روی **Start**.
3. چند ثانیه صبر کن تا manifest، آیکن‌ها و service worker رو بررسی کنه (باید همه‌چیز سبز/تیک‌خورده باشه، چون توی این پوشه از قبل آماده شده).
4. بزن روی **Package for Stores**، بعد گزینه‌ی **Android** رو انتخاب کن.
5. یک فرم کوچیک باز می‌شه: یک Package ID بهش بده (مثلا `com.novbatam.app`)، اسم اپ رو تایید کن، و روی **Generate** بزن.
6. یک فایل zip دانلود می‌شه که شامل فایل **APK** (و AAB، برای انتشار در Google Play) و اطلاعات کلید امضا (signing key) هست. همون APK همونیه که لازم داری.
7. فایل APK رو با کابل، تلگرام‌به‌خودت، گوگل‌درایو یا هر روشی به گوشی اندرویدت منتقل کن.
8. روی فایل APK بزن تا نصب بشه. اگه گوشی پیام «از منابع ناشناس نصب نشه» داد، باید یک‌بار توی تنظیمات گوشی، اجازه‌ی نصب از همون اپ (مثلا فایل منیجر یا مرورگر) رو فعال کنی — خود گوشی موقع نصب لینک مستقیم به همون تنظیمات رو نشون می‌ده.

بعد از نصب، آیکن نوبتم (همون آیکن قیچی بنفش) روی گوشیت میاد و دقیقاً مثل یک اپ نصب‌شده‌ی عادی باز می‌شه.

> اگه بعدا خواستی اپ رو توی Google Play هم منتشر کنی، همون فایل AAB داخل zip لازمت می‌شه؛ اون مسیر چند مرحله‌ی اضافه (ثبت‌نام حساب توسعه‌دهنده در Google Play Console، هزینه‌ی یک‌بار حدود ۲۵ دلار) داره که در صورت نیاز جداگانه راهنماییت می‌کنم.

## توسعه روی سیستم خودت (اختیاری)

اگه Node.js نصب داری و می‌خوای قبل از انتشار، اپ رو روی کامپیوتر خودت تست کنی:

```
npm install
npm run dev
```
